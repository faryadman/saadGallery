## فاز ۲ — بازار (نرخ‌ها)
**دامنه:** Provider/Adapter، DTO اعتبارسنجی‌شده، نگاشت JSON با تست، Cache، تاریخچه، BackgroundService دوره‌ای، مدیریت نرخ کهنه/قطع منبع، پایش سلامت منبع.

**معیار پذیرش**
- [x] قرارداد `IRateProvider` با پیاده‌سازی حداقل دو Provider (منبع اصلی + Fixture) و **مستقل** بودن آن‌ها. — `TgnRateProvider` + `FixtureRateProvider` (ADR-0012)
- [x] نگاشت JSON با نمونه واقعیِ مالک: حداقل ۶ تست واحد روی Fixture (شامل Fuzz: JSON ناقص، `null`، عدد متنی `"7,600,000"`، واحد ریال/تومان، تاریخ بدون Timezone). — ۱۹ تست پارسر + ۱۶ تست نرمال‌سازی
- [x] هیچ نرخی بدون `Unit`، `QuotedAtUtc`، `FetchedAtUtc`، `ProviderId` و وضعیت اعتبار در UI یا دیتابیس منتشر نشود (تست: بازرسی رکورد). — `NormalizedRate.FindInvariantViolations` + ستون‌های اجباری + تست مخزن
- [x] قطعی شبیه‌سازی‌شده منبع (Mock ⇒ Timeout/500/JSON نامعتبر): سیستم خراب نشود، آخرین نرخ معتبر با برچسب «آخرین نرخ ثبت‌شده» + زمان نمایش داده شود. — تست‌های HTTP + تست کش/نمایش
- [x] Job دوره‌ای: تنظیم بازه از Config، لغو با `CancellationToken`، جلوگیری از اجرای هم‌زمان (قفل درون‌فرایندی + قفل دیتابیسی برای چند نمونه)، ثبت هر اجرا در `PriceFetchRun`. — قفل اجاره‌ای `MarketFetchLease`؛ تست SQL در محیط مالک اجرا می‌شود
- [x] Rate Limit سمت خروجی (حداقل فاصله بین درخواست‌ها) با احترام به محدودیت اعلامی منبع؛ در صورت خطای 429 ⇒ Backoff نمایی. — حداقل فاصله = بازه اجرا؛ ۴۲۹ ⇒ `RateLimited` + عقب‌نشینی
- [x] Cache با انقضای قابل تنظیم؛ اندازه‌گیری: پاسخ صفحه اصلی از Cache زیر 50ms و بدون کوئری اضافی (لاگ SQL یا Counter). — ۳–۸ms اندازه‌گیری‌شده؛ تست «مسیر گرم = صفر کوئری»
- [~] تست یکپارچه: درج نرخ، خواندن «آخرین نرخ»، بررسی مقدار دهدهی — **نوشته‌شده اما اجرای واقعی نیازمند SQL Server مالک است** (۹ تست، این‌جا Skip). محاسبه «تغییر نسبت به دوره مرجع» بخشی از فاز ۳ است.
- [x] Log هر فراخوانی بدون API Key و بدون هدرهای حساس (تست: بازرسی لاگ). — دو تست بازرسی لاگ در مسیر موفق و ناموفق

- [x] کنتراست متن طبق WCAG AA و بررسی دسترس‌پذیری (حداقل: نسبت کنتراست و اندازه لمسی 44px) با ابزار انجام و نتیجه ثبت شود. — اجرای فاز ۳: ۱۷ جفت؛ آخرین اجرای فاز ۴.۱: ۲۳ جفت، همه قبول در `docs/ACCESSIBILITY.md` (ممیزی کامل مرورگری: محیط مالک)
- [x] مشاهده تمام موارد بالا برای کاربر مهمان (بدون ثبت‌نام) ممکن باشد؛ اما تاریخچه گسترده و ماشین‌حساب‌های تکمیلی با Policy سرور کنترل شوند. — `MemberFeatures`؛ تست مهمان ۳۰۲ / عضو ۲۰۰ برای صفحه و API
