## فاز ۲ — بازار (نرخ‌ها)
**دامنه:** Provider/Adapter، DTO اعتبارسنجی‌شده، نگاشت JSON با تست، Cache، تاریخچه، BackgroundService دوره‌ای، مدیریت نرخ کهنه/قطع منبع، پایش سلامت منبع.

**معیار پذیرش**
- [ ] قرارداد `IRateProvider` با پیاده‌سازی حداقل دو Provider (منبع اصلی + جایگزین یا Fixture) و **مستقل** بودن آن‌ها.
- [ ] نگاشت JSON با نمونه واقعیِ مالک: حداقل ۶ تست واحد روی Fixture (شامل Fuzz: JSON ناقص، `null`، عدد متنی `"7,600,000"`، واحد ریال/تومان، تاریخ بدون Timezone).
- [ ] هیچ نرخی بدون `Unit`، `QuotedAtUtc`، `FetchedAtUtc`، `ProviderId` و وضعیت اعتبار در UI یا دیتابیس منتشر نشود (تست: بازرسی رکورد).
- [ ] قطعی شبیه‌سازی‌شده منبع (Mock ⇒ Timeout/500/JSON نامعتبر): سیستم خراب نشود، آخرین نرخ معتبر با برچسب «آخرین نرخ ثبت‌شده» + زمان نمایش داده شود.
- [ ] Job دوره‌ای: تنظیم بازه از Config، لغو با `CancellationToken`، جلوگیری از اجرای هم‌زمان (قفل درون‌فرایندی + قفل دیتابیسی برای چند نمونه)، ثبت هر اجرا در `PriceFetchRun`.
- [ ] Rate Limit سمت خروجی (حداقل فاصله بین درخواست‌ها) با احترام به محدودیت اعلامی منبع؛ در صورت خطای 429 ⇒ Backoff نمایی.
- [ ] Cache با انقضای قابل تنظیم؛ اندازه‌گیری: پاسخ صفحه اصلی از Cache زیر 50ms و بدون کوئری اضافی (لاگ SQL یا Counter).
- [ ] تست یکپارچه: درج نرخ، خواندن «آخرین نرخ»، محاسبه تغییر نسبت به دوره مرجع مشخص (نه حدس)، بررسی مقدار دهدهی بدون خطای گردکردن.
- [ ] Log هر فراخوانی بدون API Key و بدون هدرهای حساس (تست: بازرسی لاگ).
