# گزارش فاز ۲ — بازار (نرخ‌ها)

- **تاریخ:** 2026-10-08
- **دامنه:** Provider/Adapter، DTO اعتبارسنجی‌شده، نگاشت JSON با تست، Cache، تاریخچه، BackgroundService دوره‌ای، مدیریت نرخ کهنه/قطع منبع، پایش سلامت منبع.
- **وضعیت:** پیاده‌سازی و تست‌های خودکار **انجام و اجرا شد**؛ دو مورد نیازمند محیط مالک (SQL Server واقعی و اعتبارنامه/IP سرویس نرخ) صریحاً باز است.

## ۱. آنچه ساخته و اجرا شد (شواهد واقعی)

| مورد | شاهد اجراشده |
| --- | --- |
| Build با «هشدار = خطا» | `0 Warning(s) / 0 Error(s)` |
| تست واحد | **۲۳۲/۲۳۲ سبز** |
| تست یکپارچه | **۵۵/۵۵ سبز + ۹ Skip** (۹ مورد نیازمند SQL Server واقعی) |
| اجرای زنده زنجیره با منبع نمونه | `--fetch-rates-once` → «نرخ معتبر: 15 · ردشده: 0 · کلید ناشناخته: 1 (Pelatin)» |
| نمایش زنده صفحه اصلی | ۱۵ کارت نرخ با برچسب «لحظه‌ای» + هشدار «نمونهٔ آزمایشی» |
| زمان پاسخ صفحه | ۳ تا ۸ میلی‌ثانیه (مسیر کش؛ معیار <۵۰ms محقق) |
| `/health/rates` | `HTTP 200 · Healthy` |
| حالت Production بدون اعتبارنامه | صفر تماس دیتابیس، پیام فارسی راهنما، کد خروج ۲ (fail-closed) |
| حالت Production با منبع نمونه | رد در همان راه‌اندازی با پیام فارسی |

## ۲. معیارهای پذیرش ROADMAP — وضعیت صادقانه

| معیار | وضعیت | توضیح |
| --- | --- | --- |
| قرارداد `IRateProvider` با دو پیاده‌سازی مستقل | ✅ | `TgnRateProvider` (واقعی) و `FixtureRateProvider` (نمونهٔ توسعه/تست) |
| نگاشت JSON با نمونه واقعی + ≥۶ تست Fuzz | ✅ | ۱۹ تست پارسر شامل JSON ناقص، `null`، «7,600,000»، ارقام فارسی، تاریخ بدون Timezone، ریشه نامعتبر، `Error` |
| انتشار نرخ بدون واحد/زمان/منبع/اعتبار ممنوع | ✅ | بازرسی ثابت‌ها در `NormalizedRate.FindInvariantViolations` + ستون‌های اجباری دیتابیس + تست |
| قطعی شبیه‌سازی‌شده منبع ⇒ سیستم خراب نشود | ✅ | تست‌های Timeout/500/429/JSON نامعتبر/پاسخ غول‌آسا + نگه‌داشتن کش قبلی |
| Job دوره‌ای: بازه از Config، لغو، جلوگیری اجرای هم‌زمان، ثبت `PriceFetchRun` | ✅ | قفل درون‌فرایندی + اجاره دیتابیسی + ثبت رکورد اجرا (تست SQL در محیط مالک) |
| Rate Limit خروجی + Backoff نمایی در ۴۲۹ | ✅ | حداقل فاصله = بازه اجرا؛ عقب‌نشینی نمایی با سقف؛ ۴۲۹ کد `RateLimited` |
| Cache با انقضا؛ پاسخ صفحه اصلی <۵۰ms و بدون کوئری اضافی | ✅ | ۳–۸ms اندازه‌گیری‌شده؛ تست «مسیر گرم: صفر کوئری» |
| تست یکپارچه: درج نرخ، آخرین نرخ، تاریخچه، دقت اعشار | ⚠️ نوشته‌شده، اجرا نیازمند SQL Server مالک | ۶ تست `RequiresSqlServer` (این‌جا Skip با پیام صریح) |
| لاگ هر فراخوانی بدون API Key و هدر حساس | ✅ | تست‌های بازرسی لاگ در مسیرهای موفق و ناموفق |

## ۳. آنچه در این محیط قابل اجرا نبود (شفاف)

1. **تماس واقعی با سرویس نرخ:** دامنه `webservice.tgnsrv.ir` از سندباکس ایجنت در دسترس نیست (timeout) و دسترسی آن به **IP مجاز** محدود است. پس تأیید نهایی «نرخ واقعی روز» فقط روی ماشین/سرور شما ممکن است.
2. **نوشتن در SQL Server:** سروری در دسترس نیست؛ مسیرهای دیتابیس با مخزن شبیه‌سازی‌شده تست شده‌اند و ۶ تست واقعی SQL نوشته شده که با تنظیم `SADGALLERY_TEST_SQL` اجرا می‌شوند.
3. **اعتبارنامه واقعی:** هرگز در کد/مخزن/لاگ/چت ذخیره نشد؛ از ENV خوانده می‌شود.
4. **مهاجرت روی دیتابیس واقعی:** اسکریپت‌ها تولید و بازرسی شدند (۳ جدول، ۴ ایندکس، ردیف اجاره، نگهبان‌های idempotent) اما اجرای واقعی روی SQL Server شما انجام نشده است.

## ۴. گام بعدی شما (سه دستور)

```powershell
git pull
dotnet tool restore
# ۱) اجرای مهاجرت جدول‌های بازار روی دیتابیس واقعی
dotnet ef database update --project src/SadGallery.Infrastructure --startup-project src/SadGallery.Web

# ۲) تنظیم اعتبارنامه سرویس نرخ (هرگز در فایل نوشته نشود) و آزمون زنده
setx RateOptions__Username "نام کاربری سرویس"
setx RateOptions__Password "رمز سرویس"
dotnet run --project src/SadGallery.Web --no-launch-profile -- --fetch-rates-once

# ۳) اجرای تست‌های واقعی دیتابیس
$env:SADGALLERY_TEST_SQL = "Server=localhost;Database=SadGallery_Test;Trusted_Connection=True;TrustServerCertificate=True"
dotnet test               # در ویندوز (یا در لینوکس: bash scripts/test.sh)
```

پس از گام ۲، خروجی باید «نرخ معتبر: ۱۵ · ثبت در دیتابیس: بله» و فهرست نرخ‌های روز را نشان دهد. اگر پاسخ `Unauthorized`/`Timeout` بود، یعنی IP سرور شما در فهرست مجاز سرویس نیست (سؤال `Q-API-2`).
