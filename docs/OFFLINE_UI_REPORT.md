## گزارش وظیفه: اصلاح ظاهر قطع اتصال و هشدار تکراری
وضعیت: انجام‌شده — 2026-10-16

### ۱) چه کاری انجام شد
دو هشدار موازی site.js و offline-status.js به یک اعلان شناور پایین صفحه، با رنگ‌های سرمه‌ای/طلایی، متن کوتاه، دکمه بستن 44px و safe-area تبدیل شدند. اعلان fixed است و main، سربرگ، scrollHeight یا متن فرم را جابه‌جا نمی‌کند. در اتصال مجدد یک اعلان کوتاه نشان داده و پس از 5 ثانیه پنهان می‌شود؛ اگر فوکوس روی آن باشد، تا اقدام کاربر باقی می‌ماند. چرخه قطع/وصل timer قبلی را لغو می‌کند و dismiss در همان دوره قطع محفوظ است.

کنترل حالت اتصال فقط در offline-status.js است. برچسب‌های live به آخرین نرخ ثبت‌شده و رنگ هشدار تغییر می‌کنند و صرف بازگشت شبکه آن‌ها را دوباره live نمی‌کند؛ نشان خلاصه صفحه بازار هم marker لازم را گرفت. صفحه خودکار reload و فرم خودکار ارسال نمی‌شود. site.js دیگر اعلان یا کلاس اتصال موازی نمی‌سازد.

### ۲) فایل‌های تغییر‌یافته (مسیر + نوع تغییر)
- `src/SadGallery.Web/Views/Shared/_Layout.cshtml`: اعلان تک‌نمونه، محتوای وضعیت/آیکون/دکمه و version فایل اسکریپت.
- `src/SadGallery.Web/Views/Market/Index.cshtml`: marker کیفیت برای خلاصه بازار.
- `src/SadGallery.Web/wwwroot/css/site.css`: جایگزینی نوار با اعلان fixed، رنگ‌ها، safe-area و focus.
- `src/SadGallery.Web/wwwroot/js/site.js`: حذف سازنده موازی اعلان؛ entry point عمومی محفوظ.
- `src/SadGallery.Web/wwwroot/js/offline-status.js`: حالت اتصال، dismiss، timer reconnect و برچسب محافظه‌کارانه نرخ.
- `scripts/accessibility-check.py`: جایگزینی سنجش رنگ قدیمی اعلان با رنگ واقعی جدید و افزودن متن توضیح؛ حد کنتراست 4.5 حفظ شد.
- مستندات بخش ۷.

### ۳) تست‌های اجراشده و خروجی واقعی (دستور + خلاصه نتیجه)
- `bash /workspace/.sadgallery-tools/install.sh`: restore و build با warnaserror؛ 0 Warning و 0 Error.
- `dotnet test --no-build` با تزریق امن اتصال SQL آزمایشی: 559 موفق، 0 شکست، 0 Skip. تست/Assertion موجود حذف یا ضعیف نشد.
- `python3 scripts/accessibility-check.py --write-doc`: 24 جفت‌رنگ، همه قبول؛ عنوان سفید روی سرمه‌ای 15.74:1 و متن توضیح 10.96:1؛ قواعد هدف لمسی موفق. گزارش ACCESSIBILITY به‌روز شد.
- Chromium/Playwright با context.setOffline: قطع/وصل واقعی مرورگر، یک اعلان، نبود #sg-offline-banner تکراری، main/header و scrollHeight دقیقاً ثابت، dismiss و رخداد تکراری، اعلان reconnect و timeout و لغو timer در قطع دوباره، حفظ اعلان هنگام فوکوس و بستن با Enter، موفق.
- نمایش و منو در 320×568، 390×844، افقی 844×390 و دسکتاپ 1440×1000 بدون سرریز و بدون خطای JavaScript. متن و فایل انتخاب‌شده در فرم تیکت پس از قطع/وصل باقی ماندند، URL عوض نشد و LocalStorage خالی بود.
- badge آزمایشی با marker live در DOM برای رفتار نمایشی استفاده شد: پس از قطع، آخرین ثبت شد و با اتصال مجدد live نشد؛ هیچ نرخ یا مبلغ ساختگی در داده برنامه ذخیره نشد.

### ۴) مشکلات باقی‌مانده / مسدودکننده‌ها
برای اصلاح ظاهر فعلی مسدودکننده‌ای باقی نیست. بارگذاری اولیه کاملاً آفلاین هنوز خارج از این تغییر و مربوط به فاز ۷ است. navigator.onLine سلامت سرور را ثابت نمی‌کند؛ Safari/iOS فیزیکی و اسکرین‌ریدر آزموده نشده‌اند.

### ۵) ریسک امنیتی (اجراشده، باقی‌مانده، نیازمند تصمیم مالک)
هیچ داده خصوصی یا پیش‌نویس در LocalStorage/Cache نوشته نمی‌شود؛ نگهداری فرم صرفاً همان DOM باز است. Policy، CSRF، دریافت نرخ، محدودیت آپلود و مسیرهای خصوصی تغییر نکردند. اتصال مجدد باعث reload، ارسال فرم یا ادعای دریافت نرخ تازه نمی‌شود. رویداد اتصال بدون تماس با منبع خارجی مدیریت می‌شود.

### ۶) Migration لازم است؟
خیر؛ تغییر DB/backend نیست. بازگشت View/CSS/JS امکان‌پذیر است؛ بازگشت قدیمی، باگ هشدار موازی و برچسب live پس از reconnect را نیز برمی‌گرداند.
