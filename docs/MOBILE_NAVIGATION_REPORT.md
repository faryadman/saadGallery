## گزارش وظیفه: منوی شناور و وسط‌چین موبایل
وضعیت: انجام‌شده — 2026-10-16؛ بازبینی بصری مالک باقی است.

### ۱) چه کاری انجام شد
در عرض زیر 1200px، نوار ثابت و شناور بالای صفحه با فاصله امن از لبه‌ها، برند مرکزی، دکمه منو و دسترسی سریع حساب/تیکت ساخته شد. رنگ سرمه‌ای و طلایی، گوشه‌های گرد و زمینه نیمه‌شفاف با پالت قبلی هماهنگ هستند. پنل جدا در زیر نوار، کارت‌های خانه/بازار/ویترین/تیکت، آیکون و مسیر فعال دارد؛ گروه‌های ابزار، مدیریت و حساب، لینک‌ها و نشان پیام فعلی حفظ شدند. نمایش دسکتاپ همچنان نوار قبلی است.

کنترل Bootstrap Collapse موجود بازاستفاده شد. باز/بستن، لمس بیرون، Escape، آزادسازی اسکرول و فوکوس، اسکرول داخلی در ارتفاع کم، تغییر عرض و برگشت از cache مرورگر مدیریت می‌شوند. منو disclosure ناوبری است و فوکوس را حبس نمی‌کند؛ خروج فوکوس آن را می‌بندد. Escape حتی با زیرمنوی باز در فاز capture دریافت می‌شود تا Bootstrap Dropdown آن را مصرف نکند. targetهای لمسی 44px یا بیشتر، safe-area و prefers-reduced-motion رعایت شدند. فایل CSS/JS با نسخه محتوا به HTML اضافه می‌شوند.

### ۲) فایل‌های تغییر‌یافته (مسیر + نوع تغییر)
- `src/SadGallery.Web/Views/Shared/_Layout.cshtml`: اجزای موبایل، آیکون‌ها، عنوان پنل، دسترسی نقش‌محور و backdrop؛ ارجاع اسکریپت جدید و version فایل‌ها.
- `src/SadGallery.Web/wwwroot/css/site.css`: نوار و پنل شناور، grid دسترسی سریع، badge، focus، safe-area، ارتفاع تطبیقی و reduced-motion در breakpoint موبایل.
- `src/SadGallery.Web/wwwroot/js/mobile-navigation.js`: هماهنگی Bootstrap با backdrop/اسکرول، Escape/بیرون پنل، تغییر اندازه و چرخه برگشت صفحه.
- `docs/PROJECT_STATUS.md`، `ROADMAP.md`، `CHANGELOG.md`، `KNOWN_LIMITATIONS.md` و این گزارش.

### ۳) تست‌های اجراشده و خروجی واقعی (دستور + خلاصه نتیجه)
- `bash /workspace/.sadgallery-tools/install.sh` شامل restore و build با `-warnaserror`: 0 Warning، 0 Error.
- `dotnet test --no-build` با تزریق امن اتصال SQL آزمایشی: 559 موفق، 0 شکست، 0 Skip؛ تست موجود حذف/ضعیف نشد.
- Chromium/Playwright روی Kestrel و SQL واقعی: مهمان/مشتری/اپراتور؛ نوار و برند وسط‌چین؛ ثابت‌ماندن در اسکرول و فاصله محتوا؛ مسیر فعال؛ زیرمنوها؛ badge و لینک متناسب نقش؛ خروج واقعی POST و ورود دوباره؛ کلیک، لمس بیرون، Escape با زیرمنوی باز، Enter و خروج فوکوس؛ آزادشدن اسکرول؛ تغییر عرض دسکتاپ/موبایل؛ reduced-motion؛ بازگشت صفحه؛ نبود overflow یا خطای JavaScript، موفق.
- اندازه‌ها: موبایل 320×568 و 390×844، افقی 844×390 و دسکتاپ 1440×1000. در ارتفاع کم آخرین گزینه حساب با اسکرول پنل در دسترس بود. badge چهارنویسه‌ای آزمایشی در 320px نیز سرریز نداشت.
- `python3 scripts/accessibility-check.py`: 23 جفت‌رنگ موجود و قواعد لمسی موفق؛ این ممیزی کامل منو با اسکرین‌ریدر نیست. Safari/iOS فیزیکی در محیط فعلی اجرا نشد.
- در بررسی اولیه Escape داخل Dropdown توسط listener Bootstrap مصرف می‌شد؛ دریافت در فاز capture اصلاح و همان سناریو در مرورگر دوباره موفق شد.
