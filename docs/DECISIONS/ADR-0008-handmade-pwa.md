# ADR-0008 — PWA دست‌ساز (Manifest + Service Worker) بدون Framework

- **وضعیت:** Accepted
- **تاریخ:** 2026-10-05

## زمینه
الزام: نصب روی Android و iOS به‌صورت PWA با Manifest، آیکون، Service Worker، حالت آفلاین، مدیریت Cache و وضعیت اتصال. الزام دیگر: «اطلاعات حساس را بدون ضرورت در Local Storage یا Cache قرار نده» و «نرخ‌های ذخیره‌شده باید با وضعیت و زمان خود نمایش داده شوند و هرگز به‌عنوان نرخ زنده معرفی نشوند.»

## تصمیم
PWA با فایل‌های ساده و بدون کتابخانه اضافه:
- `manifest.webmanifest` (نام، آیکون‌های 192/512 + maskable، `display: standalone`، `start_url`، رنگ‌ها، `dir: rtl`، `lang: fa-IR`).
- `service-worker.js` دست‌ساز با راهبردهای **صریح و از پیش تعیین‌شده**:
  - **Precache (نسخه‌دار):** صفحه آفلاین، فونت‌های WOFF2 سELF-host، CSS/JS اصلی، آیکون‌ها.
  - **Network-First** برای صفحات HTML احرازشده و APIهای نرخ (با سقوط به Cache و **افزودن سرآیند وضعیت آفلاین**).
  - **Cache-First** فقط برای دارایی‌های استاتیک تغییرناپذیر (فونت/آیکون/CSS با هش نام).
  - **هرگز Cache نمی‌شوند:** `POST`ها، صفحات پنل ادمین/اپراتور، پاسخ‌های حاوی داده شخصی (تیکت)، توکن‌ها.
- نسخه‌بندی Cache (`sadgallery-static-v1`) + پاک‌سازی نسخه‌های قدیم در `activate`.
- نمایش «آفلاین» با `navigator.onLine` + رویدادهای `online/offline` و بنر واضح.
- راهنمای نصب درون‌برنامه‌ای (برای iOS: «Share → Add to Home Screen»).

## دلیل
- PWA استاندارد در این پروژه به «کد کم و قابل فهم برای مالک» نیاز دارد؛ Frameworkهای PWA آماده (Workbox/next-pwa) برای یک اپ MVC ساده، حجم و لایه انتزاعی غیرضروری اضافه می‌کنند.
- کنترل صریح بر *چه چیزی کش نشود* برای رعایت الزام امنیتی حیاتی است؛ پیکربندی پیش‌فرض کتابخانه‌ها می‌تواند صفحات احرازشده را کش کند (خطر جدی).

## پیامدها
- **مثبت:** سبک، قابل بازبینی خط‌به‌خط، بدون وابستگی اضافه، کنترل کامل بر حریم داده.
- **منفی:** مدیریت دستی نسخه Cache و به‌روزرسانی SW (که با یک تست مشخص در معیار پذیرش فاز ۷ پوشش داده می‌شود).
- **محدودیت‌های iOS** (بدون پیشنهاد نصب خودکار، پاک‌شدن Storage، نبود Background Sync): پذیرفته و در `KNOWN_LIMITATIONS.md` §3 مستند شده. برای اعلان‌های آینده روی iOS، تصمیم جداگانه لازم است.

## قواعد امنیتی مرتبط (تکرار الزامی در بازبینی کد)
1. داده شخصی/احرازشده در Cache Storage و LocalStorage ذخیره نمی‌شود.
2. نرخ ذخیره‌شده همیشه حامل `quotedAtUtc`/`fetchedAtUtc` و برچسب «ذخیره‌شده/آفلاین» است.
3. صفحه آفلاین هرگز نرخ را به‌عنوان «لحظه‌ای» نمایش نمی‌دهد.
