# وضعیت پروژه SadGallery

> این فایل «تصویر لحظه‌ای حقیقت» است. در پایان هر وظیفه به‌روزرسانی می‌شود. تاریخ‌ها میلادی/UTC مگر ذکر شود.

**آخرین به‌روزرسانی:** 2026-10-16 · **فاز جاری:** ۶ — پنل مدیر و اپراتور پیاده و روی SQL آزمایشی/مرورگر آزموده؛ در انتظار بازبینی مالک. تأیید جداگانه ۴.۱ و داده محصول واقعی باقی‌اند.
**اعتبارسنجی محیط فعلی:** SDK 10.0.401، SQL Server 2022 Developer در Docker، build صفر هشدار/خطا، 598 تست موفق و صفر Skip. `/health/ready` نیز 200 شد. این نتیجه درباره دیتابیس آزمایشی cloud است، نه سرور مالک یا انتشار Production.
**داده:** محصولات آزمایشی فقط در دیتابیس تست ساخته شدند؛ در دیتابیس توسعه هیچ محصول/قیمت واقعی از طرف مالک درج نشده. منبع Fixture فقط Development و برچسب‌دار است. sms.ir انتخاب شد ولی Enabled=false و شناسه/پارامترهای الگو به درخواست مالک خالی‌اند.

## شواهد اجرای فاز ۶ — 2026-10-16
- داشبورد واقعی مشترک با آمار تیکت/محصول، آخرین دریافت/اجرای نرخ، سلامت منبع پیکربندی‌شده و فهرست تازگی/جهش نرخ‌ها. گزارش عملیاتی بدون متن/اطلاعات تماس کاربران.
- مدیریت صفحه‌بندی‌شده کاربران، جست‌وجوی نام/شناسه دقیق، نقش و وضعیت حساب با ConcurrencyStamp؛ ممنوعیت تغییر دسترسی خود، حفظ آخرین مدیر فعال با قفل تراکنشی SQL. باطل‌شدن نشست در درخواست بعد و نشست جدید مدیر/اپراتور ۳۰ دقیقه.
- StoreSettings با RowVersion برای توقف/ادامه و فاصله مجاز؛ خواندن مجدد بدون restart، خرابی خواندن مانع دریافت بیرونی. اسرار و انتخاب URL/منبع جدید فقط در پیکربندی امن استقرار باقی می‌مانند.
- AuditEvents عمومی و اتمیک برای تغییرات حساس، با Actor/UTC/IP/CorrelationId و فقط نام فیلدها؛ گزارش صفحه‌بندی‌شده/CSV حداکثر ۵۰۰ رخداد، بدون IP/CorrelationId در CSV و محافظ فرمول.
- 598 تست موفق، صفر شکست/Skip؛ build صفر هشدار/خطا، ماتریس تمام actionهای Admin/Operator، Identity واقعی/کوکی، تعارض، هم‌زمانی مدیران، rollback اتمیک Audit و canary اسرار آزموده شدند. Chromium دسکتاپ/۳۹۰ و اسکریپت موجود پالت/هدف لمسی موفق.
- مهاجرت `20261016010911_AdministrationSettingsAudit` روی Dev/Test و SQL جدا اجرا شد؛ Down و Up دوباره با حفظ داده قبلی آزموده شدند. هیچ انتشار Production یا تماس نرخ/پیامک واقعی انجام نشد.
- [گزارش کامل](PHASE6_REPORT.md) و [تصمیم معماری](DECISIONS/ADR-0020-administration-and-audit.md). OTP و MFA اجباری اجرا نشده‌اند؛ سیاست ورود و الگوی sms.ir همچنان بازند.
